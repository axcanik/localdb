Authentication

All developer requests must authenticate using your unique API Key. You can pass the key in either of the following headers:
  • X-API-KEY: your_api_key
  • Authorization: Bearer your_api_key

Endpoint Reference

POST /api/uid/add Register a new game UID 
curl -X POST "{{ request.url_root }}api/uid/add" \
  -H "X-API-KEY: your_api_key" \
  -H "Content-Type: application/json" \
  -d '{"uid": "1234567", "days": 30, "note": "Player Access"}'
import requests

url = "{{ request.url_root }}api/uid/add"
headers = {
    "X-API-KEY": "your_api_key",
    "Content-Type": "application/json"
}
payload = {
    "uid": "1234567",
    "days": 30,
    "note": "Player Access"
}

response = requests.post(url, json=payload, headers=headers)
print(response.json())
fetch("{{ request.url_root }}api/uid/add", {
  method: "POST",
  headers: {
    "X-API-KEY": "your_api_key",
    "Content-Type": "application/json"
  },
  body: JSON.stringify({
    uid: "1234567",
    days: 30,
    note: "Player Access"
  })
})
.then(res => res.json())
.then(data => console.log(data));
